# Solutions

Worked solutions, mirroring the lesson folder structure:

```
_solutions/level0/L0.1_numpy_for_robotics/lesson.py
```

They're unlocked from day one. Nobody's going to treat you like a child about it.

But there's a real cost to opening one early, and it isn't moral — it's that reading a
solution *feels* exactly like understanding it, and that feeling is not the same thing.
You'll find out which it was at the boss fight, when there's nothing to read.

The honest rule: attempt it properly, get stuck, sit with it for ten minutes, then look.
